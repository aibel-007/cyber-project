# SecureScan
## Problem Statement
Many websites are vulnerable to cyber threats due to missing security headers and insecure configurations. Existing security assessment tools are often expensive or require technical expertise. SecureScan provides a simple way to analyze website security and generate risk reports
## Features
User Registration & Login
🌐 Website URL Scanning
🔒 HTTPS Verification
🛡️ Security Header Analysis
📊 Risk Score Calculation
⚠️ Risk Level Classification (Low / Medium / High)
💡 Security Recommendations
📁 Scan Report History
📱 Responsive Cyber-Themed Dashboard
